# SF Symbol proxies (macOS → Android / Windows)

Имена файлов = имена SF Symbols из `ClevVPNMac` и shared `Theme/Components.swift`.

На Apple остаются системные SF Symbols.
На Android: `assets/icons/sf/{name}.svg` через `SfIcon`.
На Windows: `Assets/Ui/sf/{name}.svg` (+ ключевые файлы в `Assets/Ui/`).

Источник правды по списку — macOS UI.
